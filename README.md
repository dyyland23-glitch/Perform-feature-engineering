# Perform Feature Engineering & Naive Bayes Models

This repository contains practical machine learning notebooks and datasets focusing on **Feature Engineering** and **Naive Bayes classification models**, implemented in Python.

---

## 📂 Repository Contents

### **1. Jupyter Notebooks**
* [`Activity_Build a Naive Bayes model.ipynb`](https://github.com/dyyland23-glitch/Perform-feature-engineering/blob/main/Activity_Build%20a%20Naive%20Bayes%20model.ipynb): Practical implementation and evaluation of a Naive Bayes classifier.
* [`Activity_Perform feature engineering.ipynb`](https://github.com/dyyland23-glitch/Perform-feature-engineering/blob/main/Activity_Perform%20feature%20engineering.ipynb): Hands-on exercise for constructing, transforming, and extracting new features from raw datasets.
* [`Annotated follow-along guide_ Construct a Naive Bayes model with Python.ipynb`](https://github.com/dyyland23-glitch/Perform-feature-engineering/blob/main/Annotated%20follow-along%20guide_%20Construct%20a%20Naive%20Bayes%20model%20with%20Python.ipynb): Step-by-step guidance for building Naive Bayes models with Python.
* [`Annotated follow-along guide_Feature engineering with Python.ipynb`](https://github.com/dyyland23-glitch/Perform-feature-engineering/blob/main/Annotated%20follow-along%20guide_Feature%20engineering%20with%20Python.ipynb): Comprehensive guide covering feature transformation, encoding, and scaling techniques.

### **2. Datasets (`.csv`)**
* [`Churn_Modelling.csv`](https://github.com/dyyland23-glitch/Perform-feature-engineering/blob/main/Churn_Modelling.csv): Customer churn dataset used for predictive modeling and classification.
* [`nba-players.csv`](https://github.com/dyyland23-glitch/Perform-feature-engineering/blob/main/nba-players.csv): NBA player statistics dataset used for exploratory data analysis and feature engineering.
* [`extracted_nba_players_data.csv`](https://github.com/dyyland23-glitch/Perform-feature-engineering/blob/main/extracted_nba_players_data.csv): Processed subset of NBA player data following feature extraction pipelines.
